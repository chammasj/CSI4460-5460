# Cybersecurity Project Portfolio Template

A ChatGPT (vibecoded slop one-shot) website template for the Fall 2026 CSI 4460/5460 term project.

## Pages

- `/` — group name, three members, project topic, and proposal
- `/progress-one` — first progress report, due October 24, 2026
- `/progress-two` — second progress report, due November 14, 2026
- `/final-report` — final paper and presentation links, with a conference-style report outline

## Customize the template

1. In `app/page.tsx`, replace **Project Slopcode**, the topic summary, and the three member placeholders.
2. Replace every block labeled **Replace with your content** as the project develops.
3. In `app/final-report/page.tsx`, replace the placeholder final-paper and presentation-slide links.
4. Change site-wide project naming in `components/site-shell.tsx` and metadata in `app/layout.tsx`.

The report structure and dates are based on `Projects Guidelines-Fall 2026.pdf`. The final report should be linked as HTML or Word and the project URL should be emailed to the TA.
